# PuffRobot-machine_vision —— 但仔派机器视觉包
本项目由夏花编译，使用**Python3.8.16**实现。
## 如何使用？
**确保你使用的是Python3.8.16**,然后用pip执行以下命令： 

**pip install -r requirements.txt** 

之后就可以使用所有的文件了。（本教程不讨论虚拟环境的使用，若你使用了uv或conda,自行在对应虚拟环境使用，效果相同）

# Q1.都有哪些模块？
- 红绿灯亮灯检测
- 社区行人数量及状态检测（目前只支持文件）
- 车牌文字识别（使用飞桨PaddleOCR）
- 电动车状态识别
- dev文件夹中还保留了调用摄像头的工具与可搭载模型的程序。

# Q2.有什么注意事项吗？
- **所有的Python脚本都需要你手动在/images文件夹下创建新的文件夹路径**，如红绿灯的图片统一放在/images/trafficlight文件夹下。
- 初次使用ocr需要从云端下载字体资源与模型资源，需要连接中国大陆网络。之后无需联网。
